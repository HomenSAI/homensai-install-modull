- Перед работой прочитать канонический TODO, docs/RESUME.md, docs/work-state.json, docs/VERIFICATION_BACKLOG.md и docs/verification-status.json.
- Каждый шаг: исполнить → проверить → обновить TODO/RESUME/проверки → commit → GitHub → независимо проверить ref/tree → следующий шаг.
- Невыполненное отмечать NOT RUN/BLOCKED, непрошедшее FAIL; если теста ещё нет — NOT IMPLEMENTED. Непроверенное НЕ ГОТОВО.
