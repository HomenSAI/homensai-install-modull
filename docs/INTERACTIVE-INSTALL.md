# Экспериментальная интерактивная установка Linux

В доверенном исходном комплекте на поддерживаемом Linux запустите из терминала:

```sh
python -m shared.interactive_install --request-file /absolute/path/install-request.json --language ru
```

Файл JSON содержит только объект `params` операции `install-portable-linux`
из [описания API](API-DESIGN.md). Это подготовленные интегратором данные:
подписанный пакет, подпись, открытый ключ издателя, пути, режимы, оценки места
и шесть разных долговечных ключей операции. Файл не должен содержать пароли.
Сохраняйте его и используйте те же ключи после прерывания. Ключ издателя и
файл запроса нужно получить и проверить по независимому доверенному каналу:
сам факт криптографической подписи не удостоверяет издателя.

Программа проверяет запрос и журнал через `inspect-portable-linux-install`,
показывает продукт, выпуск, пути, режимы, SHA-256 открытого ключа и статус.
Проверка может создать файл блокировки рабочего каталога. Если показан
незавершённый шаг, он мог уже выполниться: изучите журнал и состояние прежде,
чем продолжать. Для вызова установки введите ровно `INSTALL`; иное значение,
конец ввода или прерывание отменяет вызов. Оболочка не выполняет автоматических
повторов. Контроллер может подготовить выпуск и runtime, опубликовать и
загрузить user-systemd units, запустить службы и проверить здоровье.
Предварительное чтение журнала не подтверждает пригодность всех последующих
шагов; например, проверка структуры wheel выполняется при запуске установки.

Строка об окончании означает запись в журнале, а не подтверждение текущего
здоровья или идентичности процесса. Доступны `ru`, `en`, `de` и другие полные
установленные языковые словари. Аргументы справки пока на английском языке.
Это ограниченный экспериментальный сценарий Linux; Windows, Docker,
автоматическая подготовка файла запроса и готовность к выпуску не заявлены.
