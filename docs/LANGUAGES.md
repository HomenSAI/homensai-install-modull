# Подключаемые языковые словари

Первые словари находятся в `shared/locales`: `ru.json`, `en.json`, `de.json`.
Формат — JSON-объект ключей и строк, например `installer.ready` содержит
`{product}`. Английский словарь задаёт набор ключей и допустимых переменных;
каждый подключаемый словарь должен иметь ровно тот же набор ключей и переменных.
В шаблонах допустимы только простые имена переменных, но не доступ к атрибутам,
индексам, преобразованиям и спецификаторам форматирования. Код языка — 2–3
строчные латинские буквы. Для добавления языка добавьте соответствующий JSON
в каталог, проверьте его с библиотекой и включите в подписанный выпуск.
Скачивание или загрузка исполняемых языковых модулей не реализованы.

Загрузчик принимает только обычный файл словаря: символические ссылки,
reparse points и специальные файлы отклоняются. На POSIX открытие не ожидает
FIFO и использует `O_NOFOLLOW` при наличии; идентичность и метаданные файла
проверяются при открытии и после чтения. Обнаруженная подмена отклоняется.
Это не аутентификация: каталог словарей и его родительские пути должны быть
доверенными, а процесс с теми же правами и гонки ФС остаются ограничением.
Windows-реализация и защита всех вариантов reparse points ещё не приняты на
реальной Windows.

Начальный Python-интерфейс: `from shared.i18n import translate`, затем
`translate("de", "installer.ready", product="Demo")`. Неизвестный язык,
ключ, неверные переменные или несовместимый словарь приводят к `LanguageError`,
а не к молчаливой замене языка. Значения переменных попадают в итоговый текст:
вызывающая сторона не должна передавать секреты и отвечает за экранирование
при выводе в HTML или другие контексты.

API 1.4 принимает необязательное поле `language` в запросе; доступные словари
возвращаются в `capabilities.result.languages`. Локализуются сообщения ошибок
API, а их машиночитаемые коды остаются прежними. Старые запросы без языка
сохраняют русские сообщения. Неразборчивый JSON и отказ загрузки словаря при
формировании ошибки обрабатываются на русском языке.

Словари содержат ограниченный набор сообщений. Перевод остальных интерфейсов
и согласование клиентских текстов остаются будущей работой. Проверка подписи пакета и
контролируемое распространение словарей обязательны: сам формат JSON не
доказывает доверенность содержимого.
