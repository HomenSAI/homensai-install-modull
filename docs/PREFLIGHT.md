# Предварительная проверка свежей установки

02.11.2026 · HomenS.AI · Serhii Khomenko

`shared.preflight.preflight_fresh` выполняет ограниченную проверку манифеста v2
и предполагаемого расположения **без создания файлов, блокировок, служб или
каталогов**. Её результат — сведения для плана, а не разрешение устанавливать.

Вход: публичный манифест v2, абсолютный корень текущей ОС, словарь
`required_bytes` с целыми неотрицательными оценками для `app`, `releases`,
`data`, `backup`, `services`, `config`, `runtime` и `reserve_bytes` для каждого
устройства. Оценки задаёт вызывающий код: модуль не вычисляет потребности
продукта, временных копий и контейнерных образов. При недостаточной оценке
результат проверки места не гарантирует успешного завершения операции.

Проверяются валидность и непересечение постоянных корней с кодом, раздельность
`app`/`releases`, отсутствие файлов и непустых каталогов в целевых путях и
запрет ссылок на существующем участке. Свободное пространство проверяется по
ближайшему существующему предку; оценки путей на одном `st_dev` суммируются,
резерв добавляется один раз к каждой группе. Несовпадение группировки с квотами,
сетевые ФС, будущие mount points и изменение состояния после проверки могут
повлиять на доступное место. Ошибка запрещает продолжение свежего сценария,
но модуль не решает, является ли обнаруженная папка прежней установкой.

Ответ содержит `checks_passed`, пути, разбивку оценок и `not_checked`. В нём
явно перечислены непроверенные права, возможность записи, совместимость
платформы/runtime, владение процессами, подлинность пакета и состояние служб.
Вызывающая сторона должна проверить всё необходимое и **повторить проверки под
общей блокировкой до записи**; данный модуль блокировку не создаёт. Результат
не доказывает пригодность хоста и не запускает установку.

Ранний локальный API 1.2 предоставляет то же через `preflight-fresh`, принимая
`manifest`, `install_root`, `required_bytes`, `reserve_bytes`. Ошибка возвращает
общий `preflight_failed`, не повторяя пути и значения. См. `API-DESIGN.md`.
Отдельный `inspect-native-fresh-package` в API 1.11 дополнительно учитывает
размеры проверенного подписанного пакета и показывает нижнюю оценку места для
его подготовки. Она не заменяет оценку всех последующих этапов установки.
Платформенные приёмки, реальные права и пользовательские данные не проверены.
