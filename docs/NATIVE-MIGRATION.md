# Экспериментальный запуск Python-миграции на POSIX

`shared.native_migration.run_python_migration` принимает абсолютные пути к
интерпретатору, каталогу проверенного выпуска и скрипту, независимые ожидаемые
SHA-256 обоих файлов, аргументы и timeout. `execute=False` по умолчанию только
проверяет файлы. Скрипт должен находиться внутри указанного выпуска, ссылки и
специальные файлы запрещены, файлы с несколькими жёсткими ссылками отвергаются.
Для запуска используется список аргументов без shell, Python `-I -B`, отдельная
группа процессов и ограниченное окружение; stdin/stdout/stderr отключены.
Изоляция `-I` исключает каталог скрипта и пользовательские site-packages из
обычного поиска импортов: продукт должен отдельно обеспечить доступность своих
проверенных зависимостей, этот механизм здесь ещё не реализован.

Ненулевой код, превышение времени или оставшиеся в группе дочерние процессы
дают `EffectIndeterminate`. При timeout группа завершается; это не доказывает
состояние базы или отсутствие процесса, покинувшего группу. Успешный код выхода
не подтверждает корректность миграции. Вызывающая сторона обязана обеспечить
остановку всех писателей, проверенный архив, надёжные источники хэшей, безопасную
обработку повторов и семантическую проверку данных. Используйте предварительную
отметку `UpdatePlan(guard_effects=True)`; она не делает порт идемпотентным.

Это не sandbox и не антивирус. Подпись пакета и разрешение исполнять код здесь
не проверяются; хэш, рассчитанный по тому же непроверенному файлу, не создаёт
доверия. Python может загружать стандартную библиотеку и другие системные файлы,
которые этот модуль не закрепляет. Возможна гонка замены путей после проверки,
особенно при доступе злоумышленника с теми же правами. Модуль не принимает
пароли через отдельный канал, не гарантирует отсутствие секретов в аргументах
процесса, не поддерживает Windows и пока не является готовым портом установки.
В тестах для вызова скрипта используется синтетический SQLite-продукт; реальный
продукт или production-цепочка доверия ещё не подключены. Хэш интерпретатора
в тестах берётся с текущего бинарника и не является независимым доказательством
его происхождения. Проверка с реальными systemd-службами пока использует другой
тестовый вызов миграции, поскольку временный Python зависит от `LD_LIBRARY_PATH`.
