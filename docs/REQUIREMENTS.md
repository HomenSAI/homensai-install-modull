# Требования к модулю (из требований владельца JobPilot, 24.10.2026)

- Полный архив перед каждой заменой; DataHome отдельно от программы; программу можно переустановить без потери данных.
- fresh / resume / upgrade / reinstall / перенос; неудачная миграция → откат.
- Секреты вне папки программы (DPAPI на Windows, файл 0600 на Linux); ключи не в Git и логах.
- Владение процессами, ACL, healthcheck, диагностика запуска с кодом причины.
- Docker и Windows — один продукт с общим кодом; чистая Win11 без зависимостей — отдельная приёмка.
- Проверка на неизменяемом снимке: install/update/restore/rollback.
- Лицензии и происхождение каждого перенесённого файла фиксируются.
